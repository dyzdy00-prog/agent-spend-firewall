How it works

A checkpoint between your agent and its wallet.

The agent holds a token, not a key. It asks the firewall to fetch a URL; the firewall reads the exact bytes it would sign, checks your rules and its own spend history, and only then pays.

AI agentholds a token · no key
↓ fetch(url)
Spend firewallreads bytes · checks rules · records spend · signs🔑 key inside
↓
Trusted sellerpaid · delivered
Breaks a rulerefused · nothing signed

What you get

A corporate card for every agent — with a limit you control.

Give agents real purchasing power without giving them your money.

Hard spending limits

Per-payment cap and rolling budgets per agent, per seller and in total. When it's used up, nothing more gets signed.

The key stays home

Agents get a revocable token. A compromised agent can ask — it can't sign, read the key or raise its own limit.

Pay the right people

Each seller's payee is pinned on the first payment or fixed by an allowlist. A switched address is refused.

Pay for delivery

Sellers that take money and return errors are blocked automatically after a few tries.

See everything, live

A dashboard and an append-only log of every payment and refusal, with links to each on-chain transaction.

Drop-in for your agent

One MCP tool for Claude or any MCP client, or a single HTTP call. Sellers don't change anything.
